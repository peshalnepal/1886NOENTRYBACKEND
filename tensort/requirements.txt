# DO NOT add opencv-python or numpy here.
#
# Both come from JetPack (system dist-packages) and MUST stay the system copy:
#   - opencv (cv2): the PyPI wheel is built WITHOUT GStreamer. A cp36 aarch64
#     wheel does exist, so `pip install` succeeds inside a
#     --system-site-packages venv and silently SHADOWS the JetPack cv2 —
#     killing every nvv4l2decoder/nvvidconv pipeline in channels/channel.py.
#     Cameras then fail to open or fall back to slow CPU decode.
#   - numpy: the system cv2 is compiled against the JetPack numpy; a pip numpy
#     of a different ABI causes import errors or silent array corruption.
#
# Verify after install:
#   python3 -c "import cv2,re;print(re.search(r'GStreamer:\s+YES',cv2.getBuildInformation()) is not None)"
